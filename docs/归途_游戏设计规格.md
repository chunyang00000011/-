# 《归途》游戏设计规格 v2.0（实现版）

> **本文档已对齐实际代码实现（2026-05-31）。**
## 1. 项目概述

**游戏名：**《归途》

**类型：**2D 侧视横版无尽飞行生存游戏

**引擎：**Godot 4.6

**画面：**横屏。小鸟视觉上从左向右飞行，背景和场景物件持续从右向左滚动。

**核心体验：**玩家操控一只迁徙中的小滨鹬，在草原、森林、雨夜和天敌追击中寻找食物、维持体力，并尽可能飞得更远。

**核心循环：**

1. 控制高度并保持飞行。
2. 通过碰撞收集食物。
3. 躲避树木、灌木、天敌和恶劣天气。
4. 在“低空食物多但障碍多”和“高空消耗低但资源少、天敌多”之间做路线选择。
5. 尽可能延长飞行距离，并记录成绩。

## 2. 屏幕与高度模型

游戏保留**横屏**设计。`0m~100m` 是玩法上的抽象高度，不表示画面必须完整展示真实 100 米空间。

### 2.1 视口

| 目标平台 | 基准分辨率 | 说明 |
| --- | --- | --- |
| PC / Web 原型 | `1280x720` | 当前项目目标 |
| 未来宽屏适配 | `16:9` 到 `21:9` | 横向扩展，保持高度映射稳定 |

### 2.2 高度映射

| 玩法高度 | 含义 | 画面作用 |
| --- | --- | --- |
| `0m` | 地面 | 最低交互带 |
| `15m` | 地面食物高度 | 低空风险区 |
| `30m` | 低空边界 | 灌木、密集障碍区 |
| `60m` | 中高空边界 | 路线选择转折点 |
| `70m` | 树冠食物高度 | 树上虫蛹/果实区域 |
| `90m` | 夜航暖光高度 | 夜间安全引导区 |
| `100m` | 高空上限 | 顶部限制 |

画面可以展示较大的纵向环境切片。小鸟应适当缩小，让背景、障碍物和高度路线都能被看清。

实现中，高度到屏幕 Y 坐标的映射为：屏幕高度的 `82%`（地面 `0m`）到 `18%`（高空 `100m`）线性插值。小鸟、食物、障碍、天敌都使用同一套转换规则（详见 `player_bird.gd`、`spawner.gd` 的 `_screen_y_for_height`）。

### 2.3 背景与小鸟布局

- 小鸟水平位置固定在画面宽度的 `43%` 处（`horizontal_focus_ratio = 0.43`）。
- 小鸟纵向位置随高度值在屏幕 `82%~18%` 之间移动。
- **背景纵向固定**：实现中背景始终保持在中位（`set_height_ratio(0.5)`），不随小鸟高度上下偏移。`scrolling_world.gd` 仍保留 `set_height_ratio` 接口与 `vertical_offset_px = 70` 的偏移能力，但 `main.gd` 始终传入固定值 `BACKGROUND_HEIGHT_RATIO = 0.5`。
  - 早期设计曾要求背景随高度反向移动以制造高度感，开发中改为固定背景，由小鸟自身的纵向位移表达高度变化，避免背景露出空白边缘。如需恢复，调整 `main.gd` 传入的比例即可。
- 天气与夜航的覆盖层（雨线、灰云、夜色、星空等）为铺满视口的全屏 `TextureRect`，不参与纵向偏移。

> 注：以上像素布局比例和速度均为各脚本中的 `@export` 变量，可在编辑器中微调。

## 3. 操作方式

### 3.1 正式操作方案

| 平台 | 输入 | 效果 | 输入动作名 |
| --- | --- | --- | --- |
| PC / Web | `W` / 上方向键 | 上升 | `bird_up` |
| PC / Web | `S` / 下方向键 | 下降 | `bird_down` |
| PC / Web | `Space` / 鼠标左键长按 | 加速 | `bird_accelerate` |
| PC / Web | `R` | 重新开始 | `restart_run` |

| 移动端未来版本 | 上滑 / 下滑 / 长按 | 上升 / 下降 / 加速 | — |

正式设计以连续上升、连续下降和长按加速为主。

### 3.2 移动规则

| 规则 | 数值 | 实现位置 |
| --- | --- | --- |

| 下降速度 | `34m/s` | `descend_speed_mps` |

| 加速卷轴速度 | `270 px/s` | `ACCEL_SCROLL_SPEED` |
| 距离换算 | `10 px = 1m` | `DISTANCE_PIXELS_PER_METER` |

## 4. 核心数值

| 数值 | 范围 | 初始值 | 作用 |
| --- | --- | --- | --- |
| 饱食度 | `0~100` | `60` | 飞行燃料，归零后进入坠落或倒地判定 |
| 高度 | `0m~100m` | `50m` | 决定路线、碰撞区域、资源和天敌风险 |
| 羽毛湿度 | `0~100` | `0` | 雨天上升，提高飞行消耗 |
| 飞行距离 | `0m+` | `0m` | 主分数，也驱动难度递进 |
| 飞行时间 | `0s+` | `0s` | 驱动夜航周期和部分事件 |

## 5. 饱食度消耗

采用统一公式，避免重复扣除。实现于 `main.gd` 的 `_consume_hunger`。

```text
每 0.5 秒最终消耗 =
基础消耗
× 湿度倍率
× 高度倍率
× 速度倍率
+ 操作额外消耗
```

> 早期设计含“风向倍率”，因风系统已移除，公式中不再包含该项。

### 5.1 基础消耗与操作消耗

| 状态 | 数值 |
| --- | --- |
| 基础消耗 | `1 / 0.5s` |
| 上升额外消耗 | `+0.5 / 0.5s` |
| 下降额外消耗 | `+0.2 / 0.5s` |
| 加速额外消耗 | `+0.7 / 0.5s` |

### 5.2 倍率表

| 变量 | 条件 | 倍率 |
| --- | --- | --- |
| 湿度 | 干燥 `0~20` | `x1.0` |
| 湿度 | 微湿 `21~50` | `x1.2` |
| 湿度 | 湿 `51~80` | `x1.5` |
| 湿度 | 浸透 `81~100` | `x2.0` |
| 高度 | `0~60m` | `x1.0` |
| 高度 | `61~100m` | `x0.8` |
| 速度 | 普通飞行 | `x1.0` |
| 速度 | 加速飞行 | `x1.4` |

## 6. 高度层与路线选择

| 高度 | 层级 | 食物 | 障碍 | 天敌风险 | 设计含义 |
| --- | --- | --- | --- | --- | --- |
| `0~30m` | 低层 | 丰富 | 高 | 低（`x0.5`） | 收益高，但障碍多 |
| `31~60m` | 中层 | 中等 | 中等 | 中等（`x1.0`） | 稳定默认路线 |
| `61~100m` | 高层 | 稀少 | 低 | 高（`x1.5`） | 消耗低，但暴露 |

> 早期设计中各高度层有“风向倾向”（低空易逆风、高空易顺风），随风系统移除而取消。

## 7. 食物系统

食物通过碰撞自动获取，不需要点击。配置在 `spawner.gd` 的 `FOOD_TYPES`。

| 食物类型 | 高度范围 | 饱食度 | 说明 |
| --- | --- | --- | --- |
| 地面昆虫 / 种子 | `0~15m` | `+8` | 需要贴近地面 |
| 灌木浆果 | `15~35m` | `+10` | 低空灌木区 |
| 树冠虫蛹 / 果实 | `35~70m` | `+12` | 需要飞到树冠高度 |
| 夜航暖光飞虫 | `70~90m` | `+5` | 仅黑夜期出现，带暖光辉光 |
| 夜航冷光 | `10~30m` | `-5` | 仅黑夜期出现，诱骗陷阱（负收益） |

> 已移除：地上鸟食诱饵（随陷阱系统）、湖面飞虫（随湖泊段）。
> 夜航暖光/冷光不在常规生成表中，由 `night_system.gd` 在黑夜期请求 `spawner.spawn_light_food()` 注入。

### 7.1 食物生成规则

| 规则 | 数值 |
| --- | --- |
| 基础判定间隔 | `1.1s`（随难度缩短，最短 `1.0s`） |
| 最小水平间距 | `240px`（资源/障碍通道共用间距） |
| 生成高度 | 在对应食物高度范围内随机 |
| 可见性 | 默认可见；黑夜期隐藏常规食物 |
| 反馈 | 食物消失、金色粒子爆发、数值浮字、按类型播放音效 |

## 8. 障碍物

> 捕鸟陷阱系统已移除，本节仅含树木与灌木。

### 8.1 树木

| 项目 | 数值 |
| --- | --- |
| 覆盖高度 | 树干 / 树冠约 `15~70m` |
| 生成判定 | 每 `3s` 判定一次，概率 `25%`（随难度升至 `40%`） |
| 碰撞效果 | 饱食度 `-10`，命中后短暂停顿 `0.3s` |
| 食物关系 | 部分树冠贴图带有虫蛹或果实意象 |

### 8.2 灌木

| 项目 | 数值 |
| --- | --- |
| 覆盖高度 | 贴地，`0~35m` |
| 生成判定 | 每 `3s` 独立判定，概率 `15%` |
| 密实灌木 | 碰撞饱食度 `-5`，停顿 `0.2s` |
| 稀疏灌木 | 碰撞饱食度 `-3` |

> 实现中树木与灌木各自独立计时判定（各 `OBSTACLE_CHECK_INTERVAL = 3s`），不再用单一 `obstacle_interval`。

## 9. 天敌系统

天敌表现为鹰、隼等大型深色剪影。

| 阶段 | 时长 | 行为 |
| --- | --- | --- |
| 出现 | `1.0s` | 从右侧或上方进入，靠近小鸟附近 |
| 蓄力 | `0.8s` | 显示红色攻击轨迹，指向小鸟当前位置 |
| 冲刺 | `0.5s` | 沿直线高速冲刺 |
| 判定 | 瞬间 | 若小鸟与攻击路径重叠则命中 |

| 结果 | 效果 |
| --- | --- |
| 命中 | 饱食度 `-12`，画面闪烁，羽毛粒子 |
| 未命中 | 天敌飞出画面左侧 |

高度影响天敌出现概率：

| 小鸟高度 | 倍率 |
| --- | --- |
| `<30m` | `x0.5` |
| `31~60m` | `x1.0` |
| `>60m` | `x1.5` |

## 10. 天气系统（雨与湿度）

> 风系统已移除。本节仅含雨天与羽毛湿度。实现于 `weather_system.gd`。

### 10.1 雨天

状态机：晴 → 灰云预警 → 毛毛雨 → 大雨 → 暴雨 → 放晴。覆盖层为全屏 `TextureRect`。

| 规则 | 数值 |
| --- | --- |
| 判定间隔 | 每 `8s` |
| 基础概率 | 12% |
| 持续时间 | `10~28s`（随难度变长） |
| 前置提示 | 雨前 `2s` 出现灰云阴影 |

| 阶段 | 时间 | 视觉 | 湿度变化 |
| --- | --- | --- | --- |
| 毛毛雨 | `0~4s` | 稀疏斜雨线 | `+3/s` |
| 大雨 | `5~8s` | 密集斜雨线 | `+6/s` |
| 暴雨 | `9s+` | 雨线 + 水雾 + 屏幕变暗 | `+10/s` |

雨停后，湿度每秒下降 `3` 点，直到恢复干燥。湿度倍率参与饱食度公式（见第 5 节）。

## 11. 夜航系统

夜航是周期性事件，不是随机事件。

| 规则 | 数值 |
| --- | --- |
| 首次触发 | `120s` |
| 周期 | 每 `120s` 一次，后续随难度缩短 |
| 总时长 | `15s` |

| 阶段 | 时长 | 视觉 | 玩法 |
| --- | --- | --- | --- |
| 黄昏 | `5s` | 天色变暗，食物颜色变淡 | 食物仍可见，但更难辨认 |
| 黑夜 | `7s` | 深蓝背景、剪影、微光 | 普通食物隐藏，进入光源路线玩法 |
| 黎明 | `3s` | 画面逐渐变亮 | 食物逐渐重新显示 |

黑夜期间：

| 光源 | 高度 | 概率 | 效果 |
| --- | --- | --- | --- |
| 暖黄色光 | `70~90m` | 每 `3s` 判定 65% | 饱食度 `+5` |
| 冷白色光 | `10~30m` | 每 `3s` 判定 35% | 饱食度 `-5` |

## 12. 失败与恢复

实现于 `main.gd`，玩家状态贴图切换于 `player_bird.gd`。

| 失败触发 | 结果 |
| --- | --- |
| 饱食度 `<=0` 且高度 `>0m` | 小鸟坠落（坠落贴图），`3s` 后游戏结束 |
| 饱食度 `<=0` 且高度 `=0m` | 小鸟倒地（倒地贴图） |
| 倒地后 `3s` 内碰到正收益食物 | 饱食度恢复到 `10`，重新起飞 |
| 倒地后未恢复 | 游戏结束 |

游戏结束界面（`hud.gd` 结算面板）显示：

- 飞行距离
- 飞行时间
- 收集食物数量
- 最高到达高度
- 历史最佳距离（存档于 `save_data.gd`，`user://homeward_save.cfg`）

## 13. 难度递进

难度主要由飞行距离驱动。纯函数实现于 `difficulty_system.gd` 的 `params_for_distance`，其他系统按距离向它查询参数。

| 飞行距离 | 难度 | 主要变化 |
| --- | --- | --- |
| `0~1000m` | 简单 | 食物充足，天敌少，天气温和 |
| `1000~3000m` | 普通 | 天敌和树木开始增多 |
| `3000~5000m` | 困难 | 夜航更频繁 |
| `5000~8000m` | 极难 | 雨天更长，多系统叠加 |
| `8000m+` | 生存 | 各类概率接近上限，需要精细操作 |

### 13.1 递增规则

| 系统 | 每 `1000m` 变化 | 上限 / 下限 |
| --- | --- | --- |
| 食物间隔 | 缩短 5% | 最短 `1.0s` |
| 天敌概率 | `+3%` | 最高 `30%` |
| 树木概率 | `+3%` | 最高 `40%` |
| 雨天时长 | `+1s` | 最长 `28s` |
| 夜航周期 | 每 `2000m` 缩短 `10s` | 最短 `80s` |

> 已移除：陷阱概率、逆风概率（随陷阱/风系统移除）。

## 14. 事件协调与公平性

各玩法系统为独立节点，未实现集中式“事件导演”。公平性通过各系统内部规则与共享间距保证：

- 资源（食物/夜光）与障碍（树/灌木）共用 `240px` 最小水平间距，避免堆叠。
- 天敌威胁“出现 1s + 蓄力 0.8s”给足玩家反应时间，且按高度调制概率。
- 前 `30s` 禁用天敌（`SAFE_START_TIME`）。
- 黑夜期隐藏常规食物，引导玩家走光源路线。

> 早期设计的“事件导演通道表”未落地为独立模块；其分流意图体现在上述各系统的间距与时序规则中。

## 18. 代码结构

主场景 `scenes/main.tscn`，根节点挂 `main.gd` 作为协调者。各玩法系统为其子节点，自管状态，通过信号或查询与 `main.gd` 协作。

| 脚本 | 角色 |
| --- | --- |
| `main.gd` | 协调者：run 状态、饱食度公式、距离/时间、失败/坠落/倒地、系统接线 |
| `scrolling_world.gd` | 横向滚动背景（双图循环），背景纵向固定 |
| `player_bird.gd` | 小鸟飞行/高度/状态贴图切换（爬升/下降/加速/受击/坠落/倒地） |
| `spawner.gd` | 食物与障碍生成；接入夜航可见性与难度参数 |
| `collectible_food.gd` / `obstacle.gd` | 单个食物 / 障碍，渲染贴图并发碰撞信号 |
| `difficulty_system.gd` | 纯函数：距离 → 难度参数 |
| `weather_system.gd` | 雨天状态机 + 湿度 + 全屏天气覆盖层 |
| `night_system.gd` | 周期性夜航 + 暖/冷光食物注入 + 夜色覆盖层 |
| `predator_system.gd` / `predator.gd` | 天敌管理器（按高度调制概率） / 单只天敌四阶段状态机 |
| `vfx.gd` | 一次性视觉特效（拾取爆发、碰撞闪光、羽毛、加速线） |
| `hud.gd` | 美术贴图 HUD（中文）：饱食/高度/湿度、距离、夜航、警告箭头、浮字、结算面板 |
| `pause_menu.gd` | ESC 暂停菜单（继续/重开/音量/返回标题）+ 版本号 |
| `intro_screen.gd` | 开场视频 → 标题 → 点击开始 |
| `audio_manager.gd` | **autoload**：BGM + 事件 SFX + Music/SFX 音量总线 |
| `save_data.gd` | **autoload**：历史最佳距离读写（`user://homeward_save.cfg`） |

两个 autoload（`AudioManager`、`SaveData`）注册在 `project.godot`。游戏脚本通过 `get_node_or_null("/root/AudioManager")` 等访问，未连接时安全跳过。
