# 《归途》游戏设计规格 v1.2

## 1. 项目概述

**游戏名：**《归途》

**类型：**2D 侧视横版无尽飞行生存游戏

**画面：**横屏。小鸟视觉上从左向右飞行，背景和场景物件持续从右向左滚动。

**核心体验：**玩家操控一只迁徙中的小滨鹬，在草原、森林、雨夜、顺逆风、人类陷阱和天敌追击中寻找食物、维持体力，并尽可能飞得更远。

**核心循环：**

1. 控制高度并保持飞行。
2. 通过碰撞收集食物。
3. 躲避树木、灌木、陷阱、天敌和恶劣天气。
4. 在“低空食物多但危险高”和“高空消耗低但资源少、天敌多”之间做路线选择。
5. 尽可能延长飞行距离，并记录成绩。

## 2. 屏幕与高度模型

游戏保留**横屏**设计。`0m~100m` 是玩法上的抽象高度，不表示画面必须完整展示真实 100 米空间。

### 2.1 视口

| 目标平台 | 基准分辨率 | 说明 |
| --- | --- | --- |
| PC / Web 原型 | `1280x720` | 当前项目目标 |
| 未来宽屏适配 | `16:9` 到 `21:9` | 横向扩展，保持高度映射稳定 |

### 2.2 高度映射

| 玩法高度 | 含义 | 画面作用 |
| --- | --- | --- |
| `0m` | 地面 / 水面 | 最低交互带 |
| `15m` | 地面食物 / 陷阱区域 | 低空风险区 |
| `30m` | 低空边界 | 灌木、密集障碍区 |
| `60m` | 中高空边界 | 路线选择转折点 |
| `70m` | 树冠食物高度 | 树上虫蛹/果实区域 |
| `90m` | 夜航暖光高度 | 夜间安全引导区 |
| `100m` | 高空上限 | 顶部限制 |

画面可以展示较大的纵向环境切片。小鸟应适当缩小，让背景、障碍物和高度路线都能被看清。

### 2.3 垂直相机 / 背景移动

小鸟拥有一个 `0~100` 的玩法高度值。当小鸟上升或下降时，背景也需要产生纵向变化：

- 小鸟水平位置保持在画面偏左中部，大约屏幕宽度的 `40%~45%`。
- 小鸟在屏幕纵向上保留一定活动空间。
- 当小鸟上升时，背景相应下移，制造“飞到更高处”的感觉。
- 当小鸟下降时，背景相应上移，制造“靠近地面”的感觉。
- 背景移动需要有上限和下限，不能露出空白区域。
- 食物、障碍物和天敌都使用同一套“高度到屏幕坐标”的转换规则。

当前背景图可以先使用保守的纵向偏移范围。如果后续发现背景高度不够，可以补充视差层或绘制更高的背景。

## 3. 操作方式

### 3.1 正式操作方案

| 平台 | 输入 | 效果 |
| --- | --- | --- |
| PC / Web | `W` / 上方向键 | 上升 |
| PC / Web | `S` / 下方向键 | 下降 |
| PC / Web | `Space` / 鼠标左键长按 | 加速 |
| 移动端未来版本 | 上滑 | 上升 |
| 移动端未来版本 | 下滑 | 下降 |
| 移动端未来版本 | 长按屏幕 | 加速 |

鼠标点击让小鸟上下移动一段距离可以保留为原型调试辅助，但正式设计以连续上升、连续下降和长按加速为主。

### 3.2 移动规则

| 规则 | 数值 |
| --- | --- |
| 高度范围 | `0m~100m` |
| 初始高度 | `50m` |
| 上升速度 | `20m/s` |
| 下降速度 | `20m/s` |
| 松手行为 | 经过约 `0.1s` 平滑后保持当前高度 |
| 普通卷轴速度 | `150 px/s` |
| 加速卷轴速度 | `270 px/s` |

## 4. 核心数值

| 数值 | 范围 | 初始值 | 作用 |
| --- | --- | --- | --- |
| 饱食度 | `0~100` | `60` | 飞行燃料，归零后进入坠落或倒地判定 |
| 体重 | `80g~200g` | `120g` | 进食后增加，会提高消耗，也会随时间缓慢回落 |
| 高度 | `0m~100m` | `50m` | 决定路线、碰撞区域、风向、资源和天敌风险 |
| 羽毛湿度 | `0~100` | `0` | 雨天上升，提高飞行消耗 |
| 飞行距离 | `0m+` | `0m` | 主分数，也驱动难度递进 |
| 飞行时间 | `0s+` | `0s` | 驱动夜航周期和部分事件 |

## 5. 饱食度消耗

采用统一公式，避免重复扣除。

```text
每 0.5 秒最终消耗 =
基础消耗
× 风向倍率
× 湿度倍率
× 体重倍率
× 高度倍率
× 速度倍率
+ 操作额外消耗
```

### 5.1 基础消耗与操作消耗

| 状态 | 数值 |
| --- | --- |
| 基础消耗 | `1 / 0.5s` |
| 上升额外消耗 | `+0.5 / 0.5s` |
| 下降额外消耗 | `+0.2 / 0.5s` |
| 加速额外消耗 | `+0.7 / 0.5s` |

### 5.2 倍率表

| 变量 | 条件 | 倍率 |
| --- | --- | --- |
| 风向 | 顺风 | `x0.6` |
| 风向 | 无风 | `x1.0` |
| 风向 | 逆风 | `x1.4` |
| 湿度 | 干燥 `0~20` | `x1.0` |
| 湿度 | 微湿 `21~50` | `x1.2` |
| 湿度 | 湿 `51~80` | `x1.5` |
| 湿度 | 浸透 `81~100` | `x2.0` |
| 体重 | `<=120g` | `x1.0` |
| 体重 | `121~150g` | `x1.1` |
| 体重 | `151~180g` | `x1.3` |
| 体重 | `181~200g` | `x1.5` |
| 高度 | `0~60m` | `x1.0` |
| 高度 | `61~100m` | `x0.8` |
| 速度 | 普通飞行 | `x1.0` |
| 速度 | 加速飞行 | `x1.4` |

### 5.3 体重回落

体重不能只增不减，否则玩家会觉得“吃东西也是惩罚”。因此加入自然回落：

| 规则 | 数值 |
| --- | --- |
| 自然回落 | 当体重高于 `120g` 时，每 `12s` 减少 `1g` |
| 过重回落 | 当体重高于 `160g` 时，每 `8s` 减少 `1g` |
| 自然回落下限 | `120g` |

## 6. 高度层与路线选择

| 高度 | 层级 | 食物 | 障碍 | 天敌风险 | 风向倾向 | 设计含义 |
| --- | --- | --- | --- | --- | --- | --- |
| `0~30m` | 低层 | 丰富 | 高 | 低 | 更容易逆风 | 收益高，但危险多 |
| `31~60m` | 中层 | 中等 | 中等 | 中等 | 平衡 | 稳定默认路线 |
| `61~100m` | 高层 | 稀少 | 低 | 高 | 更容易顺风 | 消耗低，但暴露 |

## 7. 食物系统

食物通过碰撞自动获取，不需要点击。

| 食物类型 | 高度范围 | 饱食度 | 体重 | 风险 / 说明 |
| --- | --- | --- | --- | --- |
| 地面昆虫 / 种子 | `0~15m` | `+8` | `+1g` | 需要贴近地面 |
| 地上鸟食诱饵 | `0~10m` | `+15` | `+3g` | 有 60% 概率触发陷阱 |
| 灌木浆果 | `15~35m` | `+10` | `+2g` | 可能藏在可穿透灌木中 |
| 树冠虫蛹 / 果实 | `35~70m` | `+12` | `+2g` | 需要飞到树冠高度 |
| 夜航暖光飞虫 | `70~90m` | `+5` | `+0g` | 仅夜航期间出现 |
| 湖面飞虫 | `20~50m` | `+5` | `+1g` | 仅湖泊段出现 |

### 7.1 食物生成规则

| 规则 | 数值 |
| --- | --- |
| 基础判定间隔 | `1.5s` |
| 最小水平间距 | `200px` |
| 生成高度 | 在对应食物高度范围内随机 |
| 可见性 | 默认可见，受夜航和暴雨影响 |
| 反馈 | 食物消失、粒子效果、数值浮字 |

## 8. 障碍物与陷阱

### 8.1 树木

| 项目 | 数值 |
| --- | --- |
| 覆盖高度 | 树干 / 树冠约 `0~70m` |
| 基础生成判定 | 每 `3s` 判定一次，25% 概率 |
| 最小间距 | `200px` |
| 碰撞效果 | 饱食度 `-10`，暂停 `0.3s`，弹回 `50px` |
| 食物关系 | 部分树冠带有虫蛹或果实 |

### 8.2 灌木

| 项目 | 数值 |
| --- | --- |
| 覆盖高度 | `0~35m` |
| 基础生成判定 | 每 `3s` 判定一次，15% 概率 |
| 可穿透灌木 | 40%，叶片稀疏，浆果可见 |
| 密实灌木 | 60%，碰撞后饱食度 `-5`，暂停 `0.2s` |

### 8.3 捕鸟陷阱

| 项目 | 数值 |
| --- | --- |
| 触发物 | 地上鸟食诱饵 |
| 高度 | `0~10m` |
| 安全结果 | 40%，正常获得食物 |
| 陷阱结果 | 60%，网兜或竹篮弹起 |
| 被困效果 | 饱食度 `-15`，无法操作 `3s` |
| 脱困 | `3s` 后自动挣脱；未来可加入互动提前脱困 |

## 9. 天敌系统

天敌表现为鹰、隼等大型深色剪影。

| 阶段 | 时长 | 行为 |
| --- | --- | --- |
| 出现 | `1.0s` | 从右侧或上方进入，靠近小鸟附近 |
| 蓄力 | `0.8s` | 显示红色攻击轨迹，指向小鸟当前位置 |
| 冲刺 | `0.5s` | 沿直线高速冲刺 |
| 判定 | 瞬间 | 若小鸟与攻击路径重叠则命中 |

| 结果 | 效果 |
| --- | --- |
| 命中 | 饱食度 `-12`，画面闪烁，羽毛粒子 |
| 未命中 | 天敌飞出画面左侧 |

高度影响天敌出现概率：

| 小鸟高度 | 倍率 |
| --- | --- |
| `<30m` | `x0.5` |
| `31~60m` | `x1.0` |
| `>60m` | `x1.5` |

## 10. 天气与风

### 10.1 雨天

| 规则 | 数值 |
| --- | --- |
| 判定间隔 | 每 `8s` |
| 基础概率 | 12% |
| 持续时间 | `10~18s` |
| 前置提示 | 雨前 `2s` 出现灰云阴影 |

| 阶段 | 时间 | 视觉 | 湿度变化 |
| --- | --- | --- | --- |
| 毛毛雨 | `0~4s` | 稀疏斜雨线 | `+3/s` |
| 大雨 | `5~8s` | 密集斜雨线 | `+6/s` |
| 暴雨 | `9s+` | 雨线 + 水雾 + 对比度降低 | `+10/s` |

雨停后，湿度每秒下降 `3` 点，直到恢复干燥。

### 10.2 风

| 风况 | 判定 | 基础概率 | 持续时间 | 效果 |
| --- | --- | --- | --- | --- |
| 顺风 | 每 `5s` | 20% | `6~10s` | 饱食消耗 `x0.6`，加速手感更强 |
| 逆风 | 每 `5s` | 15% | `4~8s` | 饱食消耗 `x1.4`，卷轴速度降低 20% |
| 无风 | 剩余时间 | - | 可变 | 默认状态 |

高空让顺风概率增加 30%，低空让逆风概率增加 30%。

## 11. 夜航系统

夜航是周期性事件，不是随机事件。

| 规则 | 数值 |
| --- | --- |
| 首次触发 | `120s` |
| 周期 | 每 `120s` 一次，后续随难度缩短 |
| 总时长 | `15s` |

| 阶段 | 时长 | 视觉 | 玩法 |
| --- | --- | --- | --- |
| 黄昏 | `5s` | 天色变暗，食物颜色变淡 | 食物仍可见，但更难辨认 |
| 黑夜 | `7s` | 深蓝背景、剪影、微光 | 普通食物隐藏，进入光源路线玩法 |
| 黎明 | `3s` | 画面逐渐变亮 | 食物逐渐重新显示 |

黑夜期间：

| 光源 | 高度 | 概率 | 效果 |
| --- | --- | --- | --- |
| 暖黄色光 | `70~90m` | 每 `3s` 判定 65% | 饱食度 `+5` |
| 冷白色光 | `10~30m` | 每 `3s` 判定 35% | 饱食度 `-5` |

## 12. 湖泊段

湖泊是草原 / 森林路线中的穿插地形。

| 规则 | 数值 |
| --- | --- |
| 判定 | 每飞行 `800m` |
| 概率 | 40% |
| 持续距离 | 约 `300m` |
| 低空影响 | 地面食物、诱饵、低空陷阱消失 |
| 特殊食物 | `20~50m` 出现湖面飞虫 |

## 13. 失败与恢复

| 失败触发 | 结果 |
| --- | --- |
| 饱食度 `<=0` 且高度 `>0m` | 小鸟坠落 `3s` 后游戏结束 |
| 饱食度 `<=0` 且高度 `=0m` | 小鸟倒在地面 |
| 倒地后 `3s` 内碰到食物 | 饱食度恢复到 `10` |
| 倒地后未恢复 | 游戏结束 |

游戏结束界面显示：

- 飞行距离
- 飞行时间
- 收集食物数量
- 最高到达高度
- 历史最佳距离

## 14. 难度递进

难度主要由飞行距离驱动。

| 飞行距离 | 难度 | 主要变化 |
| --- | --- | --- |
| `0~1000m` | 简单 | 食物充足，天敌少，天气温和 |
| `1000~3000m` | 普通 | 天敌和树木开始增多 |
| `3000~5000m` | 困难 | 夜航更频繁，陷阱和逆风增多 |
| `5000~8000m` | 极难 | 雨天更长，多系统叠加 |
| `8000m+` | 生存 | 各类概率接近上限，需要精细操作 |

### 14.1 递增规则

| 系统 | 每 `1000m` 变化 | 上限 |
| --- | --- | --- |
| 食物间隔 | 缩短 5% | 最短 `1.0s` |
| 天敌概率 | `+3%` | 30% |
| 树木概率 | `+3%` | 40% |
| 陷阱概率 | `+1%` | 15% |
| 逆风概率 | `+2%` | 25% |
| 雨天时长 | `+1s` | 28s |
| 夜航周期 | 每 `2000m` 缩短 `10s` | 最短 `80s` |

## 15. 事件导演系统

为了避免同屏事件堆叠导致不公平，使用事件导演系统统一调度，而不是让所有系统完全独立随机生成。

### 15.1 事件通道

| 通道 | 示例 | 是否可重叠 |
| --- | --- | --- |
| 资源通道 | 食物、暖光、湖面飞虫 | 可以，但要保持安全间距 |
| 障碍通道 | 树木、密实灌木、湖岸 | 有限制 |
| 威胁通道 | 天敌、陷阱结果 | 避免与大型障碍同时压迫 |
| 环境通道 | 雨、风、夜航 | 可以重叠，但要限制强度 |

### 15.2 公平性规则

- 不在同一个短反应窗口内同时生成天敌冲刺和无法躲避的树木。
- 威胁事件至少给玩家 `0.8s` 反应时间。
- 食物不能生成在无法碰撞或明显不合理的位置。
- 前 `30s` 禁用天敌和陷阱失败。
- 原型调试模式可以显示高度层和碰撞框。
